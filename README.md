# 🎓 คำนวณเกรดเฉลี่ย (GPA Calculator)

เว็บแอปพลิเคชันสำหรับคำนวณเกรดเฉลี่ยสะสม (GPA) จากรายวิชา หน่วยกิต และเกรดที่กรอกเข้าไป พัฒนาด้วย HTML, CSS และ JavaScript (Vanilla JS) ไม่พึ่งพา framework ภายนอก

## 🔗 ทดลองใช้งาน
👉 [เปิดเว็บแอปพลิเคชัน](https://folkkrub114-oss.github.io/gpa-calculator/)

## ✨ ฟีเจอร์
- กรอกรายวิชา หน่วยกิต และเกรดได้ไม่จำกัดจำนวน (เพิ่ม/ลบแถวได้)
- คำนวณ GPA อัตโนมัติตามสูตรมาตรฐาน (แต้มรวม ÷ หน่วยกิตรวม)
- ตรวจสอบความถูกต้องของข้อมูล แจ้งเตือนหากกรอกไม่ครบ
- แสดงข้อความ "เกียรตินิยม!" อัตโนมัติเมื่อ GPA ≥ 3.50

## 🛠️ เทคโนโลยีที่ใช้
- HTML5
- CSS3
- JavaScript (Vanilla JS — ไม่ใช้ framework)

## 💡 แนวคิดและที่มา
โปรเจกต์นี้เกิดจากความต้องการเครื่องมือคำนวณ GPA ที่ใช้งานง่าย ไม่ต้องเปิดโปรแกรมคำนวณเอง และเป็นโอกาสในการฝึกฝนพื้นฐานการเขียนโปรแกรมตั้งแต่การจัดการ DOM, การใช้ event listener, ไปจนถึงการวนลูปและคำนวณค่าสะสม

## 📚 สิ่งที่ได้เรียนรู้
- การใช้ `document.getElementById` และ `.querySelector` เพื่อจัดการ element บนหน้าเว็บ
- การใช้ `forEach` วนลูปคำนวณข้อมูลจากหลายแถว
- การแปลงชนิดข้อมูลด้วย `parseFloat`
- การเขียนเงื่อนไขด้วย `if/else` เพื่อตรวจสอบความถูกต้องของข้อมูล
